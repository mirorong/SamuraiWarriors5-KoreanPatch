# 전국무쌍 5 비공식 한글패치

스팀판 **전국무쌍 5 (SAMURAI WARRIORS 5)** 를 한국어로 즐길 수 있게 해주는 비공식 한글패치입니다.

> 📖 **설치 방법, 스크린샷, 업데이트 소식은 블로그에서 확인하세요**
> 👉 https://mirorong0323.tistory.com

## 다운로드

[**최신 버전 받기**](https://github.com/mirorong/SamuraiWarriors5-KoreanPatch/releases/latest)

Releases 페이지의 **Assets**에서 패치 zip 파일을 받으시면 됩니다.
함께 표시되는 Source code 파일은 받을 필요 없습니다.

## 안내

- 스팀 게임 언어를 **영어**로 설정해야 적용됩니다.
  (스팀 라이브러리 → 게임 우클릭 → 속성 → 일반 → 언어)
- 스팀판 전용입니다. PS4, Xbox One, 스위치판에서는 사용할 수 없습니다.
- 스팀 최신 버전 기준으로 제작했습니다. 게임이 업데이트되면 한글이 적용되지 않을 수 있으니, 이 경우 패치 업데이트를 기다려 주세요.
- dinput8.dll을 사용하는 다른 모드(해상도·프레임 개선 모드 등)를 쓰고 있다면, 설치 전에 블로그의 설치 안내를 먼저 확인해 주세요.
- 설치 전에 세이브 파일을 백업해 두시길 권장합니다.
- 오역이나 버그 제보는 블로그 댓글로 남겨주세요.
